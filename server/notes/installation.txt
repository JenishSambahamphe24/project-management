dotenv.config()	Loads environment variables from .env so you can use process.env.KEY.
const app = express()	Creates an Express app instance.
app.use(express.json())	Parses JSON request bodies automatically and stores in req.body.
app.use(helmet.crossOriginResourcePolicy({ policy: "cross-origin" }))	Allows resources like images to be loaded from other
 origins (part of Helmet’s security tools).
app.use(morgan("common"))	Logs each HTTP request in a standard "common" format (method, URL, status, time).
app.use(bodyParser.json())	Parses JSON bodies (similar to express.json() — redundant if both are used).
app.use(bodyParser.urlencoded({ extended: false }))	Parses URL-encoded form data (from HTML forms) into req.body. 
extended: false → simpler querystring parsing.
app.use(cors())	Allows API to be accessed from different origins by setting the right headers.
